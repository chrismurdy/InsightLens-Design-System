# UI kit — insightlens.com marketing site

Recreation of the public website: header, home, asset-management-platform,
about, contact, footer. Content is verbatim site copy where it was readable.

Open `index.html`. Nav links switch screens client-side.

**Reconstructed, not transcribed:** the contact form (the live site uses a Wix
form that could not be read) and all exact type sizes / paddings — the site's CSS
is not cross-origin readable. The photo marquee, the dark particle hero, the
service-icon grid, the testimonial block and the closing CTA are all real
patterns from the site.
