Square uppercase action button — use for every CTA on marketing pages and for
primary/secondary actions inside the platform.

\`\`\`jsx
<Button variant="accent" size="lg" icon="arrow_forward">Contact us</Button>
\`\`\`

Variants: \`primary\` (black, the default page CTA), \`accent\` (signal gold, for
the single most important action in a dark or photographic hero), \`secondary\`
(outlined, pairs beside a primary), \`ghost\` (quiet blue, for in-app toolbars).
Corners are always square — never add a radius.
